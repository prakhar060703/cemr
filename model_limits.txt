Gemini model token limits
=========================

Model                    Usage                       Max input tokens/request  Max output tokens/request
-----------------------  --------------------------  ------------------------  -------------------------
Gemini 3.8 Flash         Generator + user simulator   1,048,576                 65,536
Gemini 3.1 Pro Preview   Verifier                     1,048,576                 65,536
Gemini 3.1 Flash-Lite    Optional evaluation model    1,048,576                 65,536

These are model limits, not requests-per-minute or requests-per-day quotas.
The repository currently configures max_tokens to 8,192 per call.
